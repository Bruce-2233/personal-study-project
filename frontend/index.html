What do Hit / Miss / Unscored mean?
P@8
P@8 = (number of top-8 images satisfying every label condition) ÷ 8. Each evaluated query is scored separately and the 21 queries are averaged with equal weight; only queries with relevance judgments (qrels) are scored.
Hit
The image satisfies every label condition of the query (it is in the evaluation's relevant set) and counts toward P@8.
Miss
The image was returned, but at least one condition is not satisfied (e.g. right shoe type, wrong color).
Unscored
This query has no relevance judgments (free-text input, or fewer than 8 relevant images), so it is not scored; images and labels are shown only.
Re-ranking
The LR / SVM columns re-rank baseline similarity with a shoe-type classifier score. Re-ranking activates only for preset evaluation queries that specify a shoe type; the primary-color weight was tuned to 0, so color-only queries keep the baseline order. Free-text queries always fall back to the baseline order.
